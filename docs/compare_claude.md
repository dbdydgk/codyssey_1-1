## 핵심 개념 요약
1. **선형 회귀**: 독립 변수 x를 사용해 종속 변수 y의 움직임을 예측하고 설명하는 작업입니다. x는 독립적으로 변할 수 있는 값(독립 변수)이고, y는 x에 따라 종속적으로 변하는 값(종속 변수)입니다. [출처: 슬라이드 4]
2. **단순 선형 회귀 / 다중 선형 회귀**: 하나의 x 값만으로 y 값을 설명할 수 있으면 단순 선형 회귀(simple linear regression)라고 합니다. x 값이 여러 개(x1, x2, x3 등) 필요하면 다중 선형 회귀(multiple linear regression)라고 합니다. [출처: 슬라이드 4]
3. **최소 제곱법(기울기 a)**: 최소 제곱법에서 기울기는 a = (x - x평균)(y - y평균)의 합 / (x - x평균)^2의 합 (식 4.1)으로 구합니다. 공부한 시간과 성적 데이터(x평균 5, y평균 90.5)에 적용하면 a = 46 / 20 = 2.3입니다. [출처: 슬라이드 10, 12]
4. **최소 제곱법(y 절편 b)과 예측 직선**: y 절편은 b = y의 평균 - (x의 평균 × 기울기 a) (식 4.2)로 구하며, 계산하면 b = 90.5 - (2.3 × 5) = 79입니다. 그래서 예측 직선은 y = 2.3x + 79가 되고, 예측 값은 83.6, 88.2, 92.8, 97.4입니다. [출처: 슬라이드 12, 13]
5. **평균 제곱 오차(MSE)**: 오차(실제 값 - 예측 값)를 각각 제곱해서 더한 뒤 n으로 나눈 값으로, MSE = (1/n) Σ(yi - ŷi)^2입니다. 선형 회귀는 임의의 직선을 그어 MSE를 구하고, 이 값을 가장 작게 만드는 a 값과 b 값을 찾아가는 작업입니다. [출처: 슬라이드 33, 34]

## OX 퀴즈
1. x 값이 여러 개 필요한 경우를 단순 선형 회귀라고 한다.
   - 정답: X
   - 해설: x 값이 여러 개 필요하면 다중 선형 회귀이고, 하나의 x 값만으로 설명할 수 있을 때가 단순 선형 회귀입니다.
   - 출처: 슬라이드 4

2. 표 4-1 데이터에 최소 제곱법을 적용하면 기울기 a는 2.3, y 절편 b는 79이다.
   - 정답: O
   - 해설: a = 46 / 20 = 2.3, b = 90.5 - (2.3 × 5) = 79이므로 직선은 y = 2.3x + 79입니다.
   - 출처: 슬라이드 12, 13

3. 오차의 합을 구할 때 각 오차를 제곱하는 이유는 큰 오차에 더 큰 가중치를 주기 위해서이다.
   - 정답: X
   - 해설: 자료에 따르면 오차에 양수와 음수가 섞여 있어 단순히 더하면 합이 0이 될 수 있으므로, 부호를 없애려고 제곱합니다. (가중치 관련 내용은 자료에 없음)
   - 출처: 슬라이드 34

4. y = 3x + 76 직선으로 공부한 시간 데이터의 성적을 예측했을 때 평균 제곱 오차는 11.0이다.
   - 정답: O
   - 해설: 예측 점수 82, 88, 94, 100과 실제 점수 81, 93, 91, 97로 계산한 평균 제곱 오차는 11.0입니다.
   - 출처: 슬라이드 33, 41

5. 최소 제곱법은 여러 개의 입력을 처리하는 데 적합하므로 앞으로 만날 모든 상황을 해결할 수 있다.
   - 정답: X
   - 해설: 최소 제곱법만으로는 여러 개의 입력을 처리하기에 무리가 있어 모든 상황을 해결하기 어렵습니다. 그래서 '일단 그리고 조금씩 수정해 나가기' 방식을 가장 많이 사용합니다.
   - 출처: 슬라이드 27

자료에 나온 계산값은 모두 다시 계산해서 맞는지 확인했습니다. 기울기 분자 합은 46, 분모 합은 20이고, 오차 제곱합 44 ÷ 4 = 11.0입니다.
