## 공통 입력 프롬프트
네 모델 모두 새 대화에서, 시스템 프롬프트와 예시 없이 아래 프롬프트 하나만 입력함 (Zero-shot).

```
아래 [강의 자료]는 대학 '데이터마이닝' 과목 4장(가장 훌륭한 예측선) 슬라이드의 텍스트입니다.
이 자료만 사용해서 시험 대비용 정리 자료를 만들어 주세요.

[출력 형식]
## 핵심 개념 요약
1. {개념명}: {1~2문장 설명} [출처: 슬라이드 n]
(총 5개)

## OX 퀴즈
1. {문장}
   - 정답: O 또는 X
   - 해설: {1문장}
   - 출처: 슬라이드 n
(총 5문항, O와 X를 섞을 것)

[규칙]
- 강의 자료에 없는 내용은 추가하지 마세요. 근거를 찾을 수 없으면 "자료에 없음"이라고 적으세요.
- 모든 항목에 근거가 된 슬라이드 번호를 적으세요.
- 숫자와 공식은 자료에 적힌 값 그대로 사용하세요.

[강의 자료]
(강의자료 04의 슬라이드 4, 6, 8, 10, 12, 13, 27, 29, 33, 34, 41 텍스트를 붙임. 교재 저작권 때문에 원문은 생략함)
```

## 비교 기준
| 기준 | 무엇을 봤는지 |
|---|---|
| 형식 준수 | ① 개수: 요약 5개, OX 5문항 ② 항목: 정답·해설·출처를 갖췄는지, 요약 1~2문장·해설 1문장을 지켰는지, 형식 밖 내용을 덧붙였는지 ③ 간결성: 요약이 짧게 정리됐는지 ④ 가독성: 강조(볼드)나 수식 표기로 훑어보기 쉬운지 |
| 사실·출처 정확도 | 정의, 공식, 숫자가 자료와 같은지, 출처 슬라이드 번호가 맞는지 |
| 설명 충실도 | 개념 설명에 부연이 있어 자료 없이 읽어도 이해되는지, 예제 숫자(2.3, 79, 11.0 등)를 활용했는지 |
| 자료 밖 내용 없음 | 규칙대로 강의 자료에 없는 내용을 넣지 않았는지 |

## 선정 결론
**선정: Gemini 4 Hydrogen (일상생활 지원 모드, 사고 수준: 낮음, 무료 사용 가능)**

합계 점수는 Gemini 4 Hydrogen과 Gemini 4 Neon이 18점으로 같았다. 처음에는 부연설명이 많은 Neon을 골랐지만, 다시 검토한 뒤 Hydrogen으로 바꿨다.

선정 이유 (직접 작성): 1~2문장이긴 한데 Neon은 다시 보니 부연설명이 너무 길어서 가독성이 떨어진다. 애초에 핵심 요약이니 핵심만 외울 수 있도록 정리해야 하는데, 이러면 외우기도 힘들어질 것 같다. 특히 4번째 개념인 '일단 그리고 조금씩 수정해 나가기 방식'은 요약이 아니라 그냥 개념을 나열한 느낌이 크다. 그래서 Hydrogen으로 정했다.
