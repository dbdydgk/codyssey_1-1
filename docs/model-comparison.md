## 선정 결론
**선정: Gemini 4 Hydrogen (일상생활 지원 모드, 사고 수준: 낮음, 무료 사용 가능)**

합계 점수는 Gemini 4 Hydrogen과 Gemini 4 Neon이 18점으로 같았다. 처음에는 부연설명이 많은 Neon을 골랐지만, 다시 검토한 뒤 Hydrogen으로 바꿨다.

선정 이유 (직접 작성): 1~2문장이긴 한데 Neon은 다시 보니 부연설명이 너무 길어서 가독성이 떨어진다. 애초에 핵심 요약이니 핵심만 외울 수 있도록 정리해야 하는데, 이러면 외우기도 힘들어질 것 같다. 특히 4번째 개념인 '일단 그리고 조금씩 수정해 나가기 방식'은 요약이 아니라 그냥 개념을 나열한 느낌이 크다. 그래서 Hydrogen으로 정했다.

## 핵심 개념 요약

1. 선형 회귀(Linear Regression): 독립적으로 변할 수 있는 값인 독립 변수($x$)를 사용해 이에 따라 종속적으로 변하는 종속 변수($y$)의 움직임을 예측하고 설명하는 작업으로, 하나의 $x$ 값만 사용하면 단순 선형 회귀, 여러 개의 $x$ 값이 필요하면 다중 선형 회귀라고 한다. [출처: 슬라이드 4]
2. 최적의 예측선(일차 함수 그래프): 좌표 평면에 나타난 점들의 특징을 가장 잘 나타내는 직선($y = ax + b$)을 그리는 과정으로, 선형 회귀는 결국 최적의 기울기 $a$ 값과 $y$ 절편 $b$ 값을 찾아내는 작업이다. [출처: 슬라이드 8]
3. 최소 제곱법(Method of Least Squares): 입력 값($x$)과 출력 값($y$)을 이용해 일차 함수의 기울기 $a = \frac{(x - x\text{평균})(y - y\text{평균})\text{의 합}}{(x - x\text{평균})^2\text{의 합}}$와 $y$ 절편 $b = y\text{의 평균} - (x\text{의 평균} \times \text{기울기 } a)$를 바로 구하는 공식이다. [출처: 슬라이드 10, 슬라이드 12]
4. 오차(Error): 입력 데이터에 나와 있는 $y$의 '실제 값'과 $x$를 직선의 방정식에 대입해서 나오는 '예측 값'의 차이($\text{오차} = \text{실제 값} - \text{예측 값}$)이다. [출처: 슬라이드 33]
5. 평균 제곱 오차(MSE): 양수와 음수가 섞여 있는 오차의 부호를 없애기 위해 각 오차 값을 제곱해 합한 뒤 원소의 총 개수($n$)로 나눈 값으로, 공식은 $\text{MSE} = \frac{1}{n} \sum(y_i - \hat{y}_i)^2$이다. [출처: 슬라이드 34]

## 핵심 개념 요약

1. **선형 회귀**: 독립적으로 변하는 값인 독립 변수 x를 사용해 종속적으로 변하는 값인 종속 변수 y의 움직임을 예측하고 설명하는 작업입니다. 하나의 x 값만으로 y 값을 설명할 수 있으면 단순 선형 회귀(simple linear regression), x 값이 여러 개 필요하면 다중 선형 회귀(multiple linear regression)라고 합니다. [출처: 슬라이드 4]
2. **가장 훌륭한 예측선**: 주어진 점들의 특징을 가장 잘 나타내는 직선인 일차 함수 그래프 y = ax + b를 그려 내는 과정입니다. 주어진 데이터에서의 선형 회귀는 결국 최적의 기울기 a 값과 y 절편 b 값을 찾아내는 작업이라고 할 수 있습니다. [출처: 슬라이드 8]
3. **최소 제곱법(method of least squares)**: 일차 함수의 기울기 a와 y 절편 b를 바로 구할 수 있는 공식으로, 기울기 a는 a = (x - x평균)(y - y평균)의 합 / (x - x평균)^2의 합 (식 4.1)으로 계산합니다. 이는 x의 편차(각 값과 평균과의 차이)를 제곱해서 합한 값을 분모로 놓고, x와 y의 편차를 곱해서 합한 값을 분자로 놓아 기울기를 구하는 방식입니다. [출처: 슬라이드 10]
4. **일단 그리고 조금씩 수정해 나가기 방식**: 여러 개의 입력을 처리하기에 무리가 있는 최소 제곱법 대신, 가설을 하나 세운 뒤 요건 충족 여부를 판단해 긍정적이면 오차가 최소가 될 때까지 조금씩 변화를 반복하는 방법입니다. 이는 딥러닝을 가능하게 하는 가장 중요한 원리 중 하나이며, 각 선의 오차를 계산하고 오차가 작은 쪽으로 바꾸는 알고리즘이 필요합니다. [출처: 슬라이드 27]
5. **평균 제곱 오차(MSE)**: 양수와 음수가 섞인 오차를 단순히 더하면 합이 0이 될 수 있으므로, 각 오차 값을 제곱해 합한 오차의 합 = Σ(yi - ŷi)^2을 x 원소의 총 개수 n으로 나눈 값(평균 제곱 오차(MSE) = (1/n) Σ(yi - ŷi)^2)입니다. 선형 회귀는 임의의 직선을 그어 평균 제곱 오차를 구하고 이 값을 가장 작게 만들어 주는 a 값과 b 값을 찾아가는 작업입니다. [출처: 슬라이드 34]

* 정답: X
* 해설: 하나의 x 값만으로 y 값을 설명할 수 있으면 단순 선형 회귀(simple linear regression)이며, x 값이 여러 개 필요할 때 다중 선형 회귀(multiple linear regression)라고 합니다.
* 출처: 슬라이드 4

2. 최소 제곱법에서 y 절편 b를 구하는 공식은 b = y의 평균 - (x의 평균 × 기울기 a) (식 4.2)이다.

* 정답: O
* 해설: y 절편 b는 y의 평균에서 x의 평균과 기울기 a의 곱을 빼는 공식(식 4.2)으로 구합니다.
* 출처: 슬라이드 12

3. 최소 제곱법 공식으로 완성한 직선의 방정식 y = 2.3x + 79에 공부한 시간 2를 대입했을 때 나오는 예측 값은 실제 성적인 81이다.

* 정답: X

* 출처: 슬라이드 13

4. 최소 제곱법 공식은 여러 개의 입력을 처리하는 데 적합하여 앞으로 만나게 될 모든 상황을 이 공식만으로 해결할 수 있다.

* 정답: X
* 해설: 최소 제곱법은 여러 개의 입력을 처리하기에는 무리가 있어 이 공식만으로 앞으로 만나게 될 모든 상황을 해결하기는 어렵습니다.
* 출처: 슬라이드 27

5. 임의의 직선 y = 3x + 76에서 오차 = 실제 값 - 예측 값으로 계산할 때, 공부한 시간(x)이 4이고 실제 성적(y)이 93인 데이터의 오차는 5이다.

* 정답: O
* 해설: 공부한 시간(x)이 4일 때 실제 값 93에서 y = 3x + 76에 대입해 나온 예측 값 88을 빼면 오차는 5가 됩니다.

## 핵심 개념 요약
1. **선형 회귀**: 독립 변수 x를 사용해 종속 변수 y의 움직임을 예측하고 설명하는 작업입니다. x는 독립적으로 변할 수 있는 값(독립 변수)이고, y는 x에 따라 종속적으로 변하는 값(종속 변수)입니다. [출처: 슬라이드 4]
2. **단순 선형 회귀 / 다중 선형 회귀**: 하나의 x 값만으로 y 값을 설명할 수 있으면 단순 선형 회귀(simple linear regression)라고 합니다. x 값이 여러 개(x1, x2, x3 등) 필요하면 다중 선형 회귀(multiple linear regression)라고 합니다. [출처: 슬라이드 4]
3. **최소 제곱법(기울기 a)**: 최소 제곱법에서 기울기는 a = (x - x평균)(y - y평균)의 합 / (x - x평균)^2의 합 (식 4.1)으로 구합니다. 공부한 시간과 성적 데이터(x평균 5, y평균 90.5)에 적용하면 a = 46 / 20 = 2.3입니다. [출처: 슬라이드 10, 12]
4. **최소 제곱법(y 절편 b)과 예측 직선**: y 절편은 b = y의 평균 - (x의 평균 × 기울기 a) (식 4.2)로 구하며, 계산하면 b = 90.5 - (2.3 × 5) = 79입니다. 그래서 예측 직선은 y = 2.3x + 79가 되고, 예측 값은 83.6, 88.2, 92.8, 97.4입니다. [출처: 슬라이드 12, 13]
5. **평균 제곱 오차(MSE)**: 오차(실제 값 - 예측 값)를 각각 제곱해서 더한 뒤 n으로 나눈 값으로, MSE = (1/n) Σ(yi - ŷi)^2입니다. 선형 회귀는 임의의 직선을 그어 MSE를 구하고, 이 값을 가장 작게 만드는 a 값과 b 값을 찾아가는 작업입니다. [출처: 슬라이드 33, 34]
