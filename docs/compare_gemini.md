## 핵심 개념 요약

1. 선형 회귀(Linear Regression): 독립적으로 변할 수 있는 값인 독립 변수($x$)를 사용해 이에 따라 종속적으로 변하는 종속 변수($y$)의 움직임을 예측하고 설명하는 작업으로, 하나의 $x$ 값만 사용하면 단순 선형 회귀, 여러 개의 $x$ 값이 필요하면 다중 선형 회귀라고 한다. [출처: 슬라이드 4]
2. 최적의 예측선(일차 함수 그래프): 좌표 평면에 나타난 점들의 특징을 가장 잘 나타내는 직선($y = ax + b$)을 그리는 과정으로, 선형 회귀는 결국 최적의 기울기 $a$ 값과 $y$ 절편 $b$ 값을 찾아내는 작업이다. [출처: 슬라이드 8]
3. 최소 제곱법(Method of Least Squares): 입력 값($x$)과 출력 값($y$)을 이용해 일차 함수의 기울기 $a = \frac{(x - x\text{평균})(y - y\text{평균})\text{의 합}}{(x - x\text{평균})^2\text{의 합}}$와 $y$ 절편 $b = y\text{의 평균} - (x\text{의 평균} \times \text{기울기 } a)$를 바로 구하는 공식이다. [출처: 슬라이드 10, 슬라이드 12]
4. 오차(Error): 입력 데이터에 나와 있는 $y$의 '실제 값'과 $x$를 직선의 방정식에 대입해서 나오는 '예측 값'의 차이($\text{오차} = \text{실제 값} - \text{예측 값}$)이다. [출처: 슬라이드 33]
5. 평균 제곱 오차(MSE): 양수와 음수가 섞여 있는 오차의 부호를 없애기 위해 각 오차 값을 제곱해 합한 뒤 원소의 총 개수($n$)로 나눈 값으로, 공식은 $\text{MSE} = \frac{1}{n} \sum(y_i - \hat{y}_i)^2$이다. [출처: 슬라이드 34]

## OX 퀴즈

1. 독립 변수가 $x_1, x_2, x_3$ 등 여러 개 필요하여 $y$ 값을 설명하는 선형 회귀는 단순 선형 회귀라고 한다.

* 정답: X
* 해설: 하나의 $x$ 값만으로도 $y$ 값을 설명할 수 있다면 단순 선형 회귀라고 하며, $x$ 값이 여러 개 필요한 경우는 다중 선형 회귀라고 한다.
* 출처: 슬라이드 4

2. 최소 제곱법 공식은 여러 개의 입력을 처리하는 데 무리가 없으므로 앞으로 만나게 될 모든 상황을 해결할 수 있다.

* 정답: X
* 해설: 최소 제곱법은 여러 개의 입력을 처리하기에는 무리가 있기 때문에 이 공식만으로 모든 상황을 해결하기는 어렵다.
* 출처: 슬라이드 27

3. 공부한 시간($x$) 평균이 5, 성적($y$) 평균이 90.5, 기울기 $a$가 2.3일 때 최소 제곱법 공식으로 구한 $y$ 절편 $b$는 79이다.

* 정답: O
* 해설: $b = y\text{의 평균} - (x\text{의 평균} \times \text{기울기 } a)$ 공식에 대입하면 $90.5 - (2.3 \times 5) = 79$가 된다.
* 출처: 슬라이드 12, 슬라이드 13

4. 오차를 제곱하지 않고 단순히 더해 버리면 오차에 양수와 음수가 섞여 있어 합이 0이 될 수도 있기 때문에 오차가 실제로 얼마나 큰지 가늠하기에 적합하지 않다.

* 정답: O
* 해설: 오차에 양수와 음수가 섞여 있어 단순 합산 시 0이 될 수 있으므로 부호를 없애기 위해 각 오차 값을 제곱해 준다.
* 출처: 슬라이드 34

5. 직선의 방정식을 $y = 3x + 76$으로 가정했을 때, 공부시간이 2, 4, 6, 8이고 실제점수가 81, 93, 91, 97인 데이터의 평균 제곱 오차는 11.0이다.

* 정답: O
* 해설: 각 오차(-1, 5, -3, -3)를 제곱해 합한 뒤 원소 개수 4로 나눈 실행 결과의 평균 제곱 오차는 11.0이다.
* 출처: 슬라이드 33, 슬라이드 34, 슬라이드 41
