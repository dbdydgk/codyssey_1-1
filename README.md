# AI Agent에게 일 제대로 시키는 법 배우기

과업: 강의 자료로 시험 대비 요약과 OX 퀴즈 만들기

## 문서 순서
1. [모델 비교와 선정 보고서](docs/model-comparison.md): 같은 프롬프트를 모델 4종에 넣고 같은 기준으로 비교
2. [시스템 설계 문서](docs/system-design.md): 과업 정의, 페르소나, 프롬프트 v1/v2/v3, Few-shot, 검증 전략
3. [실행 로그](docs/run-log.md): 작업 기록과 편집하지 않은 10턴 이상의 대화 전문
4. [미해결 기록](docs/unresolved.md): 프롬프트를 고쳐도 해결하지 못한 과업
5. [보너스 과제](bonus.md): 프롬프트 배포(Gemini 스킬), 이미지 생성, Apps Script API 호출
